# LAST SIGNAL — Android prototype

Проект 3D survival horror от первого лица для Android на Godot 4.7.2 Stable.

Исходный проект находится в архиве `LAST_SIGNAL_source_v0.1.tar.xz`, восстановление архива и сборка APK выполняются автоматически через GitHub Actions.

## Сборка APK

Сборка запускается при каждом push в `main` или вручную через вкладку **Actions** → **Build Android APK** → **Run workflow**.

После успешной сборки открой запуск workflow и скачай artifact `LAST_SIGNAL-Android-APK`. Это тестовая debug-сборка для ARM64, не релиз Google Play.

## Состав прототипа

- 3D медблок и коридор от первого лица;
- сенсорный джойстик и свайповый обзор;
- кнопки бега, приседания, взаимодействия и фонаря;
- ключ-карта, аварийная дверь и завершение тестового участка.

Монстр, дополнительные зоны, сохранения, полная звуковая система и финальные ресурсы запланированы на следующие этапы.
